# MandateOS V2

The product gives one organization a shared SPL Token vault and recursively delegated capital authority. Controllers spend or delegate their own available allocation. Revoke invalidates one branch through ancestor checks; only the selected record is revoked. Its subtree authority returns to its parent's available balance, while tokens stay in the vault. Reclaim transfers unreserved Root capacity separately. Arena Lite reserves Root capital and a trusted verifier atomically settles a submitted winner.

This visual rebuild serves hackathon judges and operators. Story explains the mechanism through an explicit simulation. Command operates the existing integration. Arena presents funded work and settlement. The user has frozen Authority Chamber: graphite, bone, mint, copper, red, Geist Sans/Mono, and one recurring authority structure. Only Story, Command, Arena are navigation surfaces. No research or new protocol scope is authorized.

Protected: Rust, generated IDL, wallet adapters, RPC configuration, PDA derivation, instruction builders, transaction send/confirm, tests. Existing Devnet configuration is incompatible with the checked-in nine-instruction program; never bypass its gate or substitute simulated evidence.
