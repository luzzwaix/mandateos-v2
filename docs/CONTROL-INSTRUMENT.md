# MandateOS: cast authority world

The current visual-only pass replaces the rejected empty rectangular Root and
repeated beveled node boxes. The product, routes, exact monetary state and all
existing controls remain the source of truth. The attached failed images are
anti-references, not source assets.

## Composition and material

Story is one asymmetric cast strip: an oversized open Root source, a broad
Research neck, a smaller Data bend, a tapered Scraper termination, an Analysis
spur and a separate Operations arm. The different scale and orientation give
hierarchy a silhouette. Curved shoulders, a deep underside and restrained studio
reflections replace plaques, room columns, portals, stairs and background art.
The custom strip geometry and connector cast use the same reflective metal.

Anton supplies the condensed thesis. Geist supplies body text and native
financial information. The semantic palette stays graphite/bone, mint authority,
copper consequence, red local cut and brass settlement. Every label, amount,
status, action, lineage and receipt remains real DOM/SVG driven by the existing
model. No PNG or full-screen mockup renders the interface.

Command exposes the organization as a flat tree, precise selection underline,
stronger amount hierarchy and a bone inspector. Arena uses a mission basin,
three distinct submission strips, an asymmetric verifier clamp and a receipt
wing. Funding is mint, unpaid preview copper, resolved simulated settlement brass.
The mission's existing ready/funded/submitted/settled lifecycle is unchanged.

## Authored motion

`loomMotion` defines Genesis 850ms, recursion 550ms, Trace 650ms, impact 500ms,
cascade 1100ms and plane/settlement 850ms. The first 48% of delegation grows the
inbound authority connector; the child then resolves from its endpoint. Trace
traverses the selected ancestry once and changes visual focus while Root stays
present. Copper draws a volume without changing any active status. The cut
opens the Research relation; power extinguishes by depth at 200ms intervals.
Operations keeps the same geometry, coordinates and authority. The same object
loses its depth into Command's native relation anchors. Arena directs funding,
submission preview and the resolved receipt along distinct paths.

Mobile and reduced motion use static mathematical SVG projections of the same
cast topology, shoulder, underside and taper. Their labels and controls stay
native. They retain the authored subject without requiring perspective or an
animation to explain state. WebGL unavailability uses this projection as well.

## Browser evidence

`artifacts/visual-redesign/before-genesis.png` and `before-recursion.png` are
actual captures of the rejected implementation. `pass1` and `pass2` contain two
complete browser passes across Story, Trace, Blast, Cascade, Command, Arena,

## Final correction verdict

The independent reviewer scored all three annotation fixes resolved on the
production captures in `artifacts/visual-redesign/final`: mobile verifier status
clearance, desktop impact/status clearance and desktop mission/Submission C
separation. The verdict covers those fixes; it is not a photographic-parity or
live-protocol claim. All 22 required captures were valid. Frontend lint and the
production build passed. This pass did not extend protocol testing or optimize
performance; it changed visual composition, geometry, material, motion direction,
native projections and annotation placement.
